
FACETRACK — RUN COMMANDS

PROJECT FOLDER

Open a terminal and go to the project root:

cd ~/Downloads/Facial-Recognition-Attendance

1) START THE FASTAPI BACKEND

Open Terminal 1:

cd ~/Downloads/Facial-Recognition-Attendance

python -m uvicorn main:app –app-dir 09_API –reload –host 127.0.0.1 –port
8000

Backend API: http://127.0.0.1:8000

Interactive API documentation: http://127.0.0.1:8000/docs

Keep this terminal running.

2) START THE FRONTEND

Open Terminal 2:

cd ~/Downloads/Facial-Recognition-Attendance

python -m http.server 5500 –directory 08_Frontend

Open the FaceTrack frontend: http://127.0.0.1:5500

Keep this terminal running too.

3) RUN THE TEST SUITE (OPTIONAL)

Open another terminal:

cd ~/Downloads/Facial-Recognition-Attendance

python -m pytest 04_Testing -v

If pytest is not installed in the active Python environment:

python -m pip install pytest

4) RUN THE ORIGINAL STREAMLIT APP (OPTIONAL / BACKUP)

The Streamlit application is being kept as a backup. To run it, open
another terminal:

cd ~/Downloads/Facial-Recognition-Attendance

python -m streamlit run 01_Source_Code/app.py

If your original Streamlit entry point is in a different location,
adjust the path to the actual app.py file.

5) STOP A RUNNING SERVER

In the terminal running the server, press:

Ctrl + C

IMPORTANT NOTES

-   Start BOTH the FastAPI backend and frontend to use the new FaceTrack
    application.
-   Keep the backend terminal and frontend terminal open while using
    FaceTrack.
-   The frontend expects the API at http://127.0.0.1:8000/api.
-   Use the same Python environment where the project’s dependencies
    (including FastAPI, Uvicorn, NumPy, OpenCV, face_recognition, dlib,
    and python-multipart) are installed.
-   If a command says a module is missing, activate the correct virtual
    environment or install the missing dependency into that environment.
-   Do not delete the original Streamlit files; they are being retained
    as a backup.
