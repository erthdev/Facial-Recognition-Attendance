FaceTrack Frontend (Scratch and Prototype front end of what the Websit will look like) - starter UI

This is a static HTML/CSS prototype for the 08_Frontend folder.
It is intentionally not connected to the Python backend yet.

Included:
- index.html (dashboard)
- pages/enrollment.html
- pages/attendance.html
- pages/reports.html
- css/style.css
- css/layout.css
- css/components.css


Important:
- All displayed names, totals, dates, chart bars, and attendance rows are sample UI data.
- Buttons, filters, camera controls, and exports are visual placeholders for now.
- No database is read or changed.
- The API and JavaScript integration will be added in a later step.
- Google Fonts are loaded online; the system font fallback works offline.
